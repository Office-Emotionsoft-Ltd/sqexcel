# SQExcelヘルプ用サンプル入力シート

このフォルダには、オンラインヘルプの画面サンプル作成用にSQExcelで作成・出力した入力シート（.xlsx）を格納する。

- `all/`: 日本語ヘルプ用と英語ヘルプ用の両者のデータを合わせて保持した入力シート
- `blank/`: サンプルデータの設定が行われていないブランクの入力シート
- `en/`: 英語ヘルプ用（ID接頭辞 `E`）のデータで作成した入力シート
- `ja/`: 日本語ヘルプ用（ID接頭辞 `J`）のデータで作成した入力シート
- `qtxl/`: ヘルプ用サンプルデータ作成に使用するSQExcelプロジェクトファイルの置き場所
- `work/`: 主にシート自体の処理(Excel Copilotにサンプルデータを作成させる等)を試すための入力シート


元データはSQL Serverサンプルデータベース（`SQL2ExcelDB`）に投入済み。他のDB種類へは、
SQL Server上でレビュー・確定した内容を基に展開する。

このフォルダはAstroのcontent collection（`src/content/docs/`）の対象外であり、
サイトのビルド・公開物には含まれない（画面キャプチャ用の作業素材）。
