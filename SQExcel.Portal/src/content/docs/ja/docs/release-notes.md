## 表記の見方

リリースノートは公開後、以下の形式でバージョンごとに新しい順に記載します。

### v0.5.0（例：ベータ版第1弾）— 公開予定日 未定

**新機能**

- （例）入力シート作成・データ取り込み・データ出力の基本機能
- （例）SQL Server / Oracle / MySQL / MariaDB / PostgreSQL / SQLite の6DB対応

**改善**

- （例）◯◯画面の操作性向上

**不具合修正**

- （例）◯◯実行時に発生していた◯◯の不具合を修正

---

バージョン番号の付け方については [バージョン番号ポリシー](https://github.com/) を参照してください。

:::caution[アルファ版・ベータ版の位置づけ]
α版は限定検証用、β版は一般向けフィードバック収集用として提供されます。詳細は公開時にあらためて記載します。
:::
