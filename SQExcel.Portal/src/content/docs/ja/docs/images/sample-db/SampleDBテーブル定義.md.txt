# SampleDB テーブル定義

ネット広告代理店向け簡易販売管理システムをモデルにしたサンプルデータベース（SampleDB）の全テーブルの項目定義です。<br/>
E/R図・テーブル間のリレーションについては [外部キー参照のあるテーブルへのデータ挿入及び削除手順（重要）](/ja/data-entry/foreign-key-order/) を参照してください。

## テーブル一覧

| No. | テーブル物理名 | テーブル論理名 | 備考 |
|---|---|---|---|
| 1 | departments | 部門マスター | 自己参照FK（親部門） |
| 2 | employees | 従業員マスター | 担当者マスター兼用 |
| 3 | clients | 取引先マスター | |
| 4 | common_codes | 汎用コードマスタ | |
| 5 | services | サービスマスター | 広告サービス種別・料金定義 |
| 6 | quotations | 見積ヘッダー | |
| 7 | quotation_details | 見積明細 | |
| 8 | contracts | 契約ヘッダー | 見積と1:1対応 |
| 9 | contract_details | 契約明細 | |
