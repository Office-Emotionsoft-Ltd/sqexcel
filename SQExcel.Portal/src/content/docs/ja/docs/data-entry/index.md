title: 入力シートへのデータ投入方法

---

SQExcel のユーザーが一番やりたいことは、おそらく「新規データの投入（特にサンプルデータ・テストデータ）」と「既存データのメンテナンス」でしょう。この用途に応じて、入力シートへのデータ記入方法には複数の選択肢があります。

:::caution[重要：これらはいずれも SQExcel の機能ではありません]
以下で紹介する3つの方法（直接入力・関数/マクロ・Copilot）は、いずれも **Excel 標準機能または外部サービスを利用する方法**であり、SQExcel 自体が提供する機能ではありません。SQExcel が提供するのは「DB構造を正確に反映した入力フォーマット」と「そこから高速に DB へ反映する仕組み」です。

裏を返せば、**入力シートへのデータの書き込み方はユーザーが完全に自由に選べる**ということです。この自由度の高さと、Excel エコシステム（関数・マクロ・AI アシスタント）をフル活用できる点が、他の DB・Excel データ交換ツールにはない SQExcel の大きな差別化要因です。
:::

## 3つの方法

<div class="two-column-table46">

| 方法 | こんなときに |
|---|---|
| [入力シートに直接入力する](/ja/docs/data-entry/manual-entry/) | 数件〜数十件程度を手早く入力・修正したいとき |
| [関数やワークシートマクロ関数を使用する](/ja/docs/data-entry/formulas/) | Excel の関数・マクロに慣れており、規則性のある大量データを生成したいとき |
| [Microsoft 365 Copilotを利用する(お薦め)](/ja/docs/data-entry/copilot/) | 自然な文章の指示だけで、まとまった量のリアルなサンプルデータを作りたいとき |

</div>

3つの方法に共通する注意点として、外部キー参照のあるテーブル群を扱う場合は、必ず [外部キー参照のあるテーブルへのデータ挿入及び削除手順（重要）](/ja/docs/data-entry/foreign-key-order/) を確認してください。

各方法の詳しい比較は [入力シートへのデータ投入方法の比較](/ja/docs/data-entry/comparison/) にまとめています。
