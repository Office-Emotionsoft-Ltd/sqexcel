## ワークブックとワークシートの対応

1つのワークブックには、1つのテーブルグループの選択済みテーブルリストに含まれるテーブルの入力シートがまとめて作成されます。ワークシート名にはスキーマ名を除いたテーブル物理名がセットされます。

:::note[長いテーブル名の扱い]
ワークシート名は最大31文字です。テーブル名が30文字以上の場合、先頭29文字で切り、30・31文字目に2桁の16進数連番（`01`〜`FF`）を接尾辞として付与します。データ取り込み・出力時のテーブル照合はワークシート名ではなく、後述のテーブル情報ヘッダの値で行われるため、この省略によって処理が誤動作することはありません。
:::

## ワークシートの構成

:::note[🖼️ 画像プレースホルダー: `IST001_InputSheetOverallLayout.jpg`]
テーブル情報ヘッダ（1〜2行目）・項目ヘッダ（3〜7行目）・データ入力エリア（8行目以降）が1枚で見える入力シートの全体像。行番号・列番号も見えるように、下記3セクションの範囲を色分けまたは枠線で示す。
:::

### テーブル情報ヘッダ部（1〜2行目）

| セル | 内容 |
|---|---|
| A1 / C1 | 見出しラベル「テーブル名」「論理名」 |
| B1 | `スキーマ名.テーブル物理名` 形式のテーブル名 |
| D1 | テーブル論理名（DB側に論理名が登録されていない場合は非表示） |
| A2 | 見出しラベル「処理結果」 |
| B2 | データ取り込み・データ出力の処理結果メッセージがここに書き込まれる |

:::note[🖼️ 画像プレースホルダー: `IST002_TableInfoHeaderCloseup.jpg`]
A1〜D2セル付近のクローズアップ。テーブル名・論理名・処理結果ラベルとその値が読める大きさで挿入。
:::

### 項目ヘッダ部（3〜7行目）

| 行 | 内容 |
|---|---|
| 3行目 | 項目物理名 |
| 4行目 | 項目論理名（取得できない場合は行自体が省略され、以降の行が1行ずつ繰り上がる） |
| 5行目 | データ型 |
| 6行目 | 項目属性（K＝キー項目、A＝自動設定項目、N＝NULL許容項目、D＝既定値あり） |
| 7行目 | 入力対象マーク欄（`*` を入れた項目のみデータ取り込みの対象になる） |

項目列の右端には「処理成否」列・「処理失敗時メッセージ」列が追加され、行ごとの処理結果が書き込まれます（実際の書き込み例は [データ取り込みダイアログ](/ja/docs/features/io-operations/data-import-dialog/) の「処理結果の書き込み」を参照）。

:::note[🖼️ 画像プレースホルダー: `IST003_LogicalNameRowOmitted.jpg`]
論理名が登録されているテーブル（4行構成）と、論理名が登録されていないテーブル（3行構成・4行目省略）の項目ヘッダ部を並べて比較できる画像。
:::

### データ入力エリア（8行目以降）

項目ヘッダより下がデータの入力エリアです。[入力シートへのデータ投入方法](/ja/docs/data-entry/) で紹介したいずれかの方法でデータを入力します。

## データ型とセル書式の対応

入力シート作成時、テーブル項目のデータ型に応じて、Excel のセル書式が自動的に設定されます。主な対応は次の通りです（詳細な桁数範囲やデフォルト値は [入力シート作成ダイアログ](/ja/docs/features/io-operations/input-sheet-builder-dialog/) のワークシート設定タブ・列幅設定タブで調整できます）。

| データ型カテゴリ | 対応するセル書式 |
|---|---|
| 整数型（TinyInt/SmallInt/Int/BigInt） | 標準（General）、または整数表示 |
| 固定小数点型（Decimal/Numeric） | 桁数に応じた小数点表示（例：`0.0000`） |
| 浮動小数点型（Float/Real/Double） | 標準（General）、または誤差を抑えた固定桁表示 |
| 文字列型（Char/VarChar/Text/Clob 等） | 文字列（`@`）＋折り返して全体を表示 |
| 日付・時刻型（Date/Time/DateTime 等） | `yyyy/mm/dd` 等、複数の書式から選択可 |
| 真偽値型（Bit/Boolean/Number1 等） | 標準（General） |
| バイナリ型（Binary/Blob/Bytea 等） | 文字列（`@`）＋折り返して全体を表示（16進数文字列） |
| その他（Guid/Xml/Json/RowId 等） | 文字列（`@`）＋折り返して全体を表示 |

:::note[🖼️ 画像プレースホルダー: `IST004_CellFormatByDataType.jpg`]
サンプルDBのテーブル（例：quotations）の入力シートで、日付列・金額（Decimal）列・文字列列が、それぞれ意図した書式（右寄せ・桁区切り・折り返し等）で表示されている状態。
:::

:::tip[列幅もデータ型に応じて自動調整]
例えば `Char/VarChar` 等の文字列型は桁数帯（1〜10／11〜20／21〜）ごとに既定の列幅が設定されており、`Decimal/Numeric` も桁数帯によって列幅が変わります。詳細な対応表は [入力シート作成ダイアログ](/ja/docs/features/io-operations/input-sheet-builder-dialog/) の列幅設定タブで確認・変更できます。
:::

## ワークシート保護

テーブル情報ヘッダ・項目ヘッダ部まではセルロックがかけられ、データ入力エリアはロック対象外となった状態でワークシート保護がかけられます（保護の有無は入力シート作成ダイアログで設定可能）。ロックされた範囲でもセルの書式変更・行列の挿入削除・並べ替え・オートフィルターは許可されており、実質的にピボットテーブルの使用とシナリオの編集以外はすべて操作可能です。

:::note[🖼️ 画像プレースホルダー: `IST005_ProtectedRangeIndicator.jpg`]
項目ヘッダ部のセルを編集しようとして「シートが保護されています」の警告が表示された状態（保護範囲と非保護範囲の境界がわかるように、データ入力エリアの先頭行も一緒に写す）。
:::
