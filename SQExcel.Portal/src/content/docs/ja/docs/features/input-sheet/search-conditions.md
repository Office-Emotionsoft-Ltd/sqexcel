[データ出力機能について](/ja/docs/features/input-sheet/data-export/) で説明した検索条件行（A列に `C` を記入した行）の、各データ型ごとの具体的な記入規則です。

:::note[🖼️ 画像プレースホルダー: `SCH001_MixedConditionExample.jpg`]
1つの入力シートに、数値条件・日付範囲条件・文字列部分一致条件を含む検索条件行が複数並んだ状態（本ページで紹介する表記例のうち代表的なものを実際に入力した状態）。
:::

## 検索条件が指定できる項目型

| 指定可能 | 指定不可 |
|---|---|
| 整数型・固定小数点型・浮動小数点型 | バイナリ型（Binary/Blob/Raw 等） |
| 文字列型（Char/VarChar/Text 等） | Clob（文字ラージオブジェクト） |
| 日付時刻型（Date/Time/DateTime 等） | Interval（Oracle期間型） |
| 真偽値型（Bit/Boolean 等） | |
| その他（UniqueId/Xml/Json/RowId 等） | |

## 数値項目

| 表記例 | 意味 |
|---|---|
| `100` | `= 100` |
| `= 100` | `= 100` |
| `100< AND < 9999` | 100より大きく9999未満（範囲指定は演算子の間に検索値を配置） |
| `< 100 OR >9999` | 100未満または9999超 |
| `(null)` | `IS NULL` |
| `<>(null)` | `IS NOT NULL` |

使用できる比較演算子は `=`, `>`, `>=`, `<`, `<=`, `<>` の6種類です。`BETWEEN`, `AND`, `NOT`, `OR`, `IN` といった SQL 予約語は使用できません（結合には `AND`/`OR` を1つだけ使用可能）。数値はカンマ区切り（`999,999,999`）でも記入できます。

## 日付時刻項目

書式は入力シートの日付セルの表示形式に厳密に合わせる必要はありません（`2027/4/1`、`2027-04-01`、`'9-May-27'` 等いずれも認識されます）。演算子・範囲指定・NULL判定の考え方は数値項目と同じです。

:::caution[DB種類による違い]
- **Oracle**：`NLS_DATE_FORMAT` に依存するため、内部で `TO_DATE(...)` / `TO_TIMESTAMP(...)` にラップされます
- **SQLite**：日付専用の型がないため、テーブル項目が Text 型で定義されている場合は文字列条件（前方一致等）扱いになり比較演算子は使用できません。Numeric 型で定義されている場合は入力シートの日付書式とテーブル側の格納書式を必ず一致させてください（一致しないと不一致と判定されます）
:::

## 真偽値項目

| 表記例 | 意味 |
|---|---|
| `TRUE` / `true` | `= TRUE` |
| `FALSE` / `false` | `= FALSE` |
| `(NULL)` | `IS NULL` |

使用できる演算子は `=` と `<>` のみです。生成される SQL は DB種類によって異なります（例：SQL Server は `= 1` / `= 0`、PostgreSQL は `= TRUE` / `= FALSE`）。

## 文字列項目

| 記号 | 意味 |
|---|---|
| `%` / `*` | 部分一致ワイルドカード（複数文字） |
| `_` | 部分一致ワイルドカード（1文字） |
| `"..."` | 複数の検索値を区切る際に個々の値を囲む |
| `,` | `"..."` で囲んだ複数の検索値を OR で結合する |
| `\LF` | 改行コードを含む |
| `\EMP` | 空白文字列（`=''`） |

### よく使う表記例

| 表記例 | 意味 |
|---|---|
| `000*` | 「000」で始まる（前方一致） |
| `*999` | 「999」で終わる（後方一致） |
| `"0001","0002"` | 「0001」または「0002」と完全一致（OR） |
| `"*@gmail.com" , "*@outlook.*"` | 複数条件のOR結合 |
| `(null)` | `IS NULL` |
| `\EMP` | 空文字列 |

:::caution[LIKE検索の大文字小文字の区別はDBによって異なる]
| DB種類 | 区別の有無 |
|---|---|
| PostgreSQL | 区別**あり**（`LIKE` はどのDBでも共通して使用し、`ILIKE` は使用しません） |
| Oracle | 区別あり（ASCIIのみ） |
| SQL Server | コレーション依存（通常は区別しない） |
| MySQL / MariaDB / SQLite | 区別なし（既定） |
:::

### シングルクォート・ダブルクォートを含む値

セル内の `'`（シングルクォート）はエスケープ不要でそのまま入力できます（SQL文内では自動的に `''` 等へ変換されます）。`"`（ダブルクォート）は複数値の区切り記号として特別な意味を持つため、リテラルとして使いたい場合は `\"` のようにエスケープしてください。

## IS NULL / IS NOT NULL / 空文字列の指定（共通）

| 条件 | 記述方法 |
|---|---|
| IS NULL | `(null)` または `(NULL)` |
| IS NOT NULL | `<>(null)` または `<>(NULL)` |
| 空文字列である（文字列項目のみ） | `\EMP` または `\emp` |
| 空文字列でない（文字列項目のみ） | `<>\EMP` または `<>\emp` |

これらの条件を記入したセルには、それ以外の内容を含めることはできません。他の条件と組み合わせることもできません。
