このセクションでは、SQExcel の各画面・各ダイアログについて、画面構成と操作を詳しく説明します。「取り敢えず使ってみよう」や「実際の開発で使ってみよう」で操作の流れを掴んだ後、個々の設定項目の意味や操作時の画面の挙動を辞書的に調べたいときに参照してください。

| ページ | 内容 |
|---|---|
| [スタートページ](/ja/docs/features/start-page/) | 起動直後に表示され、最近使ったプロジェクトの選択やクイックモード・新規プロジェクトの入り口となる画面 |
| [ホーム画面](/ja/docs/features/home-screen/) | プロジェクト・アプリDB・接続を追加・編集・削除し、IO操作画面へ遷移する画面 |
| [IO操作画面](/ja/docs/features/io-operations/) | テーブルグループの編集と、入力シート作成・データ取り込み・データ出力の各ダイアログを起動する画面 |
| [入力シート作成ダイアログ](/ja/docs/features/io-operations/input-sheet-builder-dialog/) | 入力シート作成時のオプション詳細 |
| [データ取り込みダイアログ](/ja/docs/features/io-operations/data-import-dialog/) | データ取り込み時のオプション詳細 |
| [データ出力ダイアログ](/ja/docs/features/io-operations/data-export-dialog/) | データ出力時のオプション詳細 |
| [オプション設定ダイアログ](/ja/docs/features/option-settings-dialog/) | SQExcel 全体の設定項目（ツール → オプション） |

:::tip[画面の操作フロー自体は「操作の流れとデータモデル階層」で先に確認]
本セクションは画面・ダイアログ単位のリファレンスのため、複数画面をまたぐ一連の操作の流れ（プロジェクト作成→アプリDB追加→接続追加→テーブルグループ作成→入力シート操作）を掴みたい場合は、先に [操作の流れとデータモデル階層](/ja/docs/operation-flow/) を参照してください。
:::
