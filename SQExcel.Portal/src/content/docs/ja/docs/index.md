**SQExcel（SQL2Excel）** は、データベースと Excel の間でデータをやり取りする Windows アプリケーションです。

開発時のテストデータ投入から、運用中のデータメンテナンスまで。システム開発者・運用担当者のためのツールです。

---

## SQExcel ならではの特徴

SQExcel は「入力シート」と呼ぶExcelワークブックを中心に、データの登録・更新・削除・検索を行います。

**1. 入力シートを自動生成**

データベースの構造を読み取り、項目名・データ型・主キーなどの情報が入った Excel シートを作成します。文字列項目には改行を含むテキストも入力できます。

**2. シートからデータベースへ反映**

Excel の関数やマクロ、Microsoft 365 Copilot で自由にデータを作成し、シートから INSERT・UPDATE・UPSERT・DELETE を実行します。実行内容は SQL スクリプトとして保存もできます。

**3. 検索条件を書いてデータを出力**

シートに検索条件を書いて実行すると、該当データが出力されます。出力したデータをそのまま書き換えて UPDATE することも可能です。

ワークブック内の入力シート1つ1つが「テーブル構造の説明書」「データ入力フォーム」「処理結果の記録」を兼ねる。これが SQExcel の一貫した使い方です。

---

## こんな場面で使えます

- **直ぐに使用したいとき** → クイックモードで、すぐにデータを見る・直す
- **開発中** → テストデータ・初期データの投入や変更に
- **運用中** → 保守フェーズのデータメンテナンスに
- **開発から運用まで** → 同じ入力シートを使い続けて、スムーズに引き継ぎ

規模別の使い方は [実際の開発で使ってみよう](/ja/docs/real-world/) で紹介しています。

---

## 主な機能

| 機能 | 説明 |
|------|------|
| 入力シート作成 | テーブル定義から Excel シートを自動生成 |
| データ取り込み | シートから DB へ INSERT / UPDATE / UPSERT / DELETE |
| データ出力 | 検索条件を指定して DB から Excel へ出力 |
| プロジェクト管理 | データ管理対象のシステム全体を定義 |
| アプリDB管理 | システムが使う DB を「アプリDB」として管理（複数種類にも対応） |
| 接続管理 | 環境（開発・結合テスト・本番など）ごとの接続をアプリDB単位で管理 |
| テーブルグループ管理 | 大量のテーブルをグループ化して扱いやすく |

## 対応データベース

| DB 種類 | 既定ポート | 補足 |
|---------|-----------|------|
| SQL Server | 1433 | 2012 以降 |
| Oracle | 1521 | 12c 以降（クライアント別途インストール不要） |
| MySQL | 3306 | 5.7 以降 |
| MariaDB | 3307 | 10.4 以降 |
| PostgreSQL | 5432 | 12 以降 |
| SQLite | — | ファイル形式（サーバー不要） |

クラウドデータベースを中心に、対応 DB は今後も追加予定です。
